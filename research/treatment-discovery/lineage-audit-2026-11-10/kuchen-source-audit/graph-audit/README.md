# Reconstructed lineage assertions and incomplete-outcome bounds

Reviewed 2026-11-10. **All 9,356 recorded children were retained, with 9,014 consistent recorded parent-child links.** The first structural run reconciles every pair in the seven source sheets. It finds 342 recorded components but only 171 conservative related groups once external ancestry and source lineage labels are respected. These counts are not original founders or certified independent observations.

Alongside this source audit, the [exact compatibility method](compatibility-bounds/README.md) passed exhaustive synthetic verification on 7,381 mask patterns and 69,905 completions, followed by an independent exact-state check of 4,290 larger mask compositions. It bounds paired binary covariance while leaving missing outcomes unknown. No empirical survival lag, covariance, treatment contrast or fitted biological model has been calculated here. Novelty is unestablished; no cancer mechanism or cure has been identified.

Checks requiring absent ancestors remain unavailable; they are not affirmative evidence of observation completeness.

The four negative loss durations and one division without a successor pair remain explicit. They affect five conservative groups. The remaining 166 groups have no issue detected by these rules, but this does not certify complete tracking, unbiased inclusion or independence. All groups remain in the graph; there is no clean-group or future-complete selection.

The graph contains 342 external ancestor references and 342 recorded root observations, as separate kinds of object. An external reference has no fabricated birth, death or observed episode. A consistent recorded daughter pair describes the export's assertions; it does not prove that all biological offspring or later descendants were observed. Unknown biological descendant cardinality remains unknown even when both recorded daughter assertions are consistent.

The practical value is a defensible provenance and grouping layer. Splitting these 342 components as though they were unrelated would separate records connected by known ancestry assertions or source lineage labels. The 171 broader groups are a conservative grouping aid, not a guarantee that groups are independent.

## Reproducibility and review

The [protocol](protocol.json) and [freeze record](freeze-record.json) were fixed before the first new graph construction. The [producer freeze](producer-freeze.json) pins the code and its 38 constructed fixtures before source execution.

An [independent implementation review](implementation-review.md) checked exact identifiers, formula handling, ambiguous ancestry, missing branches and source preservation. It independently reran the fixtures and compared cycle handling against Boolean transitive closure for all 530 directed graphs with one to three nodes. A [fresh-path reproduction](reproduction.json) exactly matched all seven full private graph/provenance payloads, with only top-level creation times excluded and each artifact hash independently checked. Its [stricter roster comparator](reproduction-freeze-v2.json) was pinned after both graph runs but before the first comparison; both freeze records and fixture summaries are retained, and the unused earlier comparator source remains in local history. The [independent source comparison](independent-comparison-v3.json) subsequently passed 1,603,255 field/set/bookkeeping comparisons with zero mismatches. It reconstructed source XML, identities, chronology, ancestry, components and successors separately; producer issue-code naming/bookkeeping was checked internally rather than independently recoded. Numeric residual differences were at most 2.85×10⁻¹⁴ under a 10⁻⁹ comparison threshold. This comparison threshold is distinct from the graph's 10⁻⁶ arithmetic-consistency tolerance and from unknown imaging precision.

The first independent source run stopped on one extra empty formatting cell, rap1 R1; three completed control-sheet reference graphs survive in its excluded partial failure artifact. A narrow, separately pinned parser correction accepted only truly empty extra header cells, then reconstructed all seven sheets before inspecting producer outputs. The first comparison found 9,356 adapter-token mismatches because it expected `null` where the producer and protocol used `unresolved` for event boundaries. The corrected adapter reused the unchanged independent reference; additional tracking/absorbing-mask checks are explicitly post-first-comparison. Both failures, original code versions and correction history are preserved in the [independent verification and replay guide](independent-verification.md). No graph data, original field or model outcome was repaired.

Every source field retains its workbook hash, exact sheet, XML path, Excel row/cell, storage type, raw token, resolved text and parse status. Formula text and cached tokens are preserved but not trusted as identity or arithmetic evidence. Raw sources and expanded per-cell graphs remain in excluded local storage. Public artifacts contain original code, provenance and aggregate findings.

```sh

  --private-output research/treatment-discovery/sources/lineage-2026-11-10/kuchen-graph-2026-11-10/derived/local-reproduction \
  --out tmp/kuchen-local-reproduction.json
```

Use unused output names. The expanded records stay excluded from publication.
