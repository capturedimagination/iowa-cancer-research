# Independent exact-bounds review

The independent follow-up passed on its first run: all **4,290** nine-pattern count vectors for five and six pairs. An integer-state dynamic program recovered every attainable `(A,B,J)` total, where `A` and `B` count positives on each side and `J` counts joint positives. It agreed exactly with the production fixed-margin formulas and rational endpoints. Both endpoint witnesses were valid at every tested margin, in canonical and reversed row order: **132,132 witness checks**. No empirical masks, cell graphs or random draws entered this work.

This follow-up was designed after the original analyst's successful N=0–4 enumeration, then [planned](independent-plan.json) and [pinned](independent-freeze.json) before its own N=5–6 run. The independent reference uses a literal table of allowed complete-pair contributions and set addition; production helpers never construct its reference states. The two count-vector rosters have 1,287 and 3,003 entries, respectively. Their 51,818 attainable-state entries are computational states, not biological observations or independent statistical samples. The [first result](independent-verification.json) retains every count and input hash; terminal exit was zero. The [checker](../../../../../../scripts/verify_lineage_bounds_independent.py) uses the Python standard library and ran under CPython 3.12.14.

For a fixed roster, row permutations leave these target statistics unchanged, so count vectors cover all distinct mask compositions at these sizes. We additionally reversed row order to exercise the constructive witnesses. This is not a separate enumeration of every row permutation or every literal unknown-bit assignment. The reference recurrence is exact: start with `(0,0,0)` and add each allowed binary pair's contribution to every reachable previous state. Induction on the rows gives precisely all feasible totals.

## Algebra and witness review

For the symmetrized target, write `D=A+B` and `C=J/N-D²/(4N²)`. Group masks into `d` known 11 pairs, `e` known discordant pairs, `f` pairs with one known 1 and one unknown, `g` pairs with one known 0 and one unknown, and `h` fully unknown pairs. The known positive total is `L=2d+e+f`. At `D=L+k`, the least possible joint count is `d+max(0,k-g-h)`: the `g` zero-partner slots and the first positive in each fully unknown pair absorb `g+h` positives without forming a joint pair. The largest is `d+min(k,f+h,floor((k+f)/2))`. Fill the one-cost joint pairs first, then the two-cost pairs; excess positives can occupy non-joint slots. These capacity arguments justify the implementation and its witness order. The independent DP checks all feasible fixed-D margins, rather than only the final global endpoints.

For the ordered target, `N² C=NJ-AB`. Fix `A=a`; each completed row contributes `(N*x-a)*y`. Hence an unknown second bit is optimally 1 on first-bit 1 rows for maximization and on first-bit 0 rows for minimization. Among unknown first bits, assigning a 1 has upper-objective gains `N`, `N-a`, and `0` when the observed second bit is 1, unknown, and 0, respectively. The lower-objective gains are `0`, `a`, and `N` in the reverse order. This gives the production greedy priorities and fixed-A formulas, including `a=0` and `a=N` ties. Direct witness compatibility and independent attainable-state membership were checked before assessing each requested objective value.

The two targets differ. For a given completed roster, `C_sym=C_ordered-(A-B)²/(4N²)`. Symmetrizing eliminates arbitrary within-pair labelling from the target; it does not assert that the two original marginals were equal. Their endpoint intervals must therefore retain distinct labels.

## Scope and disposition

No blocking mathematical or implementation issue was found. The earlier exhaustive N=0–4 verification also tests one-bit refinement, all within-pair label flips for the symmetrized target, an unattainable-zero example and abstract shared-variable/ancestry constraints. This review inspected that code but did not rerun it or independently certify full event-history feasibility.

The endpoints are sharp for the Cartesian set of independent unknown-bit completions. Shared cell identities, ancestry and absorbing extinction can make an endpoint witness impossible for the actual record graph. In that case these remain outer bounds. An interval containing zero does not prove that zero is an attainable completion. Nothing here establishes a confidence interval, a population covariance, original-cohort eligibility, inherited biology, or treatment relevance. The result is useful as a transparent computational component for a later, separately justified observation-mask analysis. Partial identification and finite binary optimization are established ideas; this verification makes no novelty or publication-priority claim. The existing [proposal](../compatibility-proposal.md) contains the bounded prior-art context; no additional literature search was conducted for this implementation review.

[Machine-readable review](independent-review.json) records the exact hashes, tests and exclusions. The original production code, protocol, freeze and first verification report were unchanged.
